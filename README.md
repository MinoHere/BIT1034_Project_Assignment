# Student Performance Analysis System

A Python-based application developed for the BIT1034 Advanced Programming group project.

The system imports student performance data from CSV, cleans the dataset, stores records in SQLite, provides CRUD operations, performs statistical analysis, generates visualisations and predicts final grades using machine learning.

## Main Features

- CSV dataset import
- Data cleaning and duplicate removal
- SQLite database storage
- Student record viewing and searching
- Add, update and delete student records
- Performance analytics and charts
- Final-grade prediction
- CSV report export
- Streamlit graphical interface

## Technologies Used

- Python
- Streamlit
- SQLite
- Pandas
- Plotly
- Scikit-learn
- Joblib
